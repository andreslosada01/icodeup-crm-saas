# Flujos End-to-End Demo Fase 5

## 1. Flujo SuperAdmin Icodeup

1. Iniciar sesion con `superadmin@demo.icodeup.local`.
2. Abrir Gobierno SaaS.
3. Revisar empresas demo, planes, suscripciones y modulos.
4. Entrar a Modulos y validar activacion por empresa.
5. Revisar auditoria y salud del sistema.
6. Explicar que Icodeup puede gobernar la plataforma sin exponer empresas entre si.

## 2. Flujo Admin Empresa

1. Iniciar sesion con `admin.andina@demo.icodeup.local`.
2. Abrir Mi Empresa.
3. Revisar plan Business, modulos contratados y branding.
4. Abrir usuarios, roles y permisos.
5. Revisar operacion de clientes, cobranzas, documentos y reportes.
6. Mostrar auditoria tenant si el permiso esta disponible.

## 3. Flujo Gestor

1. Iniciar sesion con `gestor1.andina@demo.icodeup.local`.
2. Abrir Mi Operacion o Cola de gestion.
3. Buscar un cliente prioritario.
4. Abrir el detalle del cliente.
5. Registrar gestion con tipificacion.
6. Crear promesa si aplica.
7. Registrar pago demo si corresponde.
8. Revisar actividad reciente y proxima accion.

## 4. Flujo Juridico

1. Iniciar como `abogado.andina@demo.icodeup.local`.
2. Confirmar que el menu se concentra en Inicio, Juridico, Documentos y Clientes en lectura.
3. Abrir Juridico.
4. Consultar casos demo asignados.
5. Revisar etapa, riesgo y vencimiento.
6. Explicar actuaciones, audiencias y documentos asociados.
7. Recalcar que el abogado no ve Gobierno SaaS, ventas ni cobranzas completas.

## 5. Flujo Documental

1. Abrir Documentos.
2. Consultar documentos de clientes, acuerdos y casos.
3. Mostrar que no se duplican datos entre cobranzas y juridico.
4. Explicar que la fase actual registra metadatos y deja listo storage seguro por tenant.

## 6. Flujo Comercial

1. Iniciar como `comercial.andina@demo.icodeup.local`.
2. Confirmar que el menu se concentra en Inicio, Ventas y Clientes en lectura.
3. Abrir Ventas.
4. Consultar leads demo asignados.
5. Revisar oportunidades y etapas del pipeline.
6. Explicar que el producto puede crecer hacia CRM 360.
7. Recalcar que el asesor comercial no ve Gobierno SaaS, juridico ni documentos si no tiene permiso.

## 7. Flujo Ejecutivo

1. Abrir Tablero y Reportes BI.
2. Revisar cartera total, recuperado, promesas, pagos y riesgo.
3. Revisar semaforos y alertas.
4. Revisar productividad por gestor.
5. Conectar los indicadores con decisiones: priorizar alto riesgo, confirmar promesas, escalar juridico y medir recuperacion.
