# Roadmap de Migracion V1 a V2

## V1

La V1 queda congelada en `versions/v1-prototipo-funcional` como prototipo operativo.

## V2 Fase 1: Base Arquitectonica

- Crear estructura modular.
- Definir configuracion por ambiente.
- Separar frontend y backend.
- Definir modelos base.
- Preparar migraciones.

## V2 Fase 2: Core SaaS

- Login seguro.
- Roles y permisos.
- Empresas cliente.
- Proyectos/carteras.
- Usuarios, lideres y equipos.
- Aislamiento tenant.

## V2 Fase 3: Operacion CRM

- Clientes.
- Repartos/importacion.
- Cola de gestion.
- Actividad/bitacora.
- Promesas y pagos.

## V2 Fase 4: Parametrizacion

- Tipificaciones por empresa/proyecto.
- Canales.
- Variables de scoring.
- Campos dinamicos por proyecto.

## V2 Fase 5: Produccion

- PostgreSQL.
- Auditoria.
- Observabilidad.
- Backups.
- CI/CD.
- Entorno test/staging/produccion.
